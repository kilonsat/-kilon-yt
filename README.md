# Kilon - YouTube Downloader Script for Termux

أداة بسيطة وذكية مكتوبة بلغة **Bash** لتسهيل تسريع عملية تحميل الفيديوهات والصوتيات من يوتيوب بجودات مختلفة مباشرة عبر تطبيق **Termux** على الأندرويد، مع ميزة التحديث التلقائي للمعرض ومكتبة الموسيقى.

## المتطلبات الأساسية
قبل استخدام السكريبت، تأكد من تثبيت الأدوات التالية داخل Termux:
```bash
pkg update && pkg upgrade
```
```bash
pkg install python ffmpeg termux-api
```
```bash
pip install yt-dlp
```
## طريقة التثبيت والاستخدام محلياً
1. افتح ملف الإعدادات في الترمكس:
```bash
nano ~/.bashrc
```
2. انسخ كود الدالة Kilon الموجود في ملف kilon.sh والصقه في نهاية ملف .bashrc.
اضغط علا ctrl-o وضغط علا enter وضغط علا ctrl-x
3. احفظ الملف واخرج، ثم قم بتحديث الطرفية عبر الأمر:
```bash
source ~/.bashrc
```
# أمثلة على الاستخدام
لاستدعاء الأداة وتنزيل أي فيديو أو صوت، استخدم الصيغة التالية:
```bash
Kilon [الجودة] [الرابط]
```
. تحميل صوت MP3 بأعلى جودة:
```bash
Kilon mp3 "رابط_الفيديو"
```
. تحميل فيديو بجودة 720p:
```bash
Kilon 720p "رابط_الفيديو"
```
. تحميل فيديو بجودة 1080p:
```bash
Kilon 1080p "رابط_الفيديو"
```
